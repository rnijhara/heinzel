# 14. Name it Heinzel

- Status: Accepted
- Date: 2026-11-16

## Context
The name shouldn't tie the project to one agent, and long names make long tool names.

## Decision
- The project, plugin and server are `heinzel`, after the Heinzelmännchen of Cologne.
- Commands are `/heinzel` and `/heinzel-setup`.

## Consequences
The README explains the name in one line.
